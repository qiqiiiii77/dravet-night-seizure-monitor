# NightGuard · 夜间发作判据引擎

> 「罕见·无界」黑客松 · 赛题5 · 提交算法层方案
> 许可：[MIT](LICENSE) · 语言：Python 3.11+（引擎只依赖 numpy）· 测试：292 项全通过

**这不是产品，是一个在真实临床数据上跑出来的算法验证结果，包含达不到的部分。**

核心数字必须成对看：

> **致命级发作（继发全身化 + 阵挛期，与 SUDEP 相关）23 次检出 23 次，代价是误报 6.70 次/10 夜。**

单位换算：致命级队列 242h / 38 夜 = 6.37 小时/夜，`6.70 次/10夜` = `0.105 次/小时`。
（不等于 0.67 次/小时 —— 次/夜 和 次/小时 混用会把结论说错 6 倍。）

## 一、先说和赛题需求书的差距

赛题 PRD V1.0 的要求我们并没有全部满足。把差距写在最前面，而不是藏在后面。

| 赛题要求 | 我们的实际情况 |
|---|---|
| 非功能需求「**完全无穿戴、无束缚**」 | ❌ **全部结论基于佩戴式传感器**（胸贴 + 耳后贴片）。这是数据集的硬约束，绕不过去。判据本身与前端形态无关 —— 换雷达/摄像头拿到心率和体动后仍适用 |
| 功能需求①五路融合（心率/呼吸/血氧/体温/体动） | ⚠️ **只实测过心率和体动**。呼吸只能从 ECG 反推（覆盖率 72%，单独增益 0.7 个点）；**血氧和体温所用数据集根本没有通道** |
| 最强调的「**隐匿发作**」（不抽搐、只僵住发呆） | ❌ **抓不到**。发作时心率确实升 1.0–1.83 倍，但背景有 **10.8% 的时间**也超过自身 1.5 倍。换传感器无用，是信噪比问题，不是硬件问题 |
| 功能需求②分级预警 | ✅ 已做，但**与赛题的「一级静默」有分歧**，理由见第三节，这是我们实测后主动否决的设计 |
| 功能需求③夜间事件时间轴 | ✅ 已做（`engine/timeline.py`，34 项测试） |
| 功能需求④多监护人协同 | ❌ 未做（纯应用层） |
| 功能需求⑤低刺激硬件交互 | ❌ 未做（无硬件层） |
| 功能需求⑥发热监护模式 | ❌ 未做 |
| 非功能需求「低误报优先级最高」 | ⚠️ 实测 6.70 次/10 夜，自定目标 3.2 次/10 夜（0.05 次/小时），**差 2.1 倍**。三种"货币"用完后这是硬下限 |

样本量也要说清：**致命级发作仅 23 次**。要达到 recall ≥99% 的认证口径需要 161 次。

## 二、三个最有用的结论（给后来者省时间）

**1. 绝对阈值一定失效，必须个体化。**
「心率 > 120 报警」这类规则在真实数据上直接崩：有患者睡眠期心率中位数就是 130。
22 位患者中 13 位的发作分数低于**自身**背景 P95。
正确做法是个体基线**并列**而非替换全局特征 —— 替换式归一化会抹掉共同信号：
0.6767 → 并列后 0.7635，误报降 34%。
这条直接对应赛题需求①里的「个体化基线」。

**2. 分级报警里不能有「静默档」。**
赛题设计的一级预警是「房间设备完全静默零打扰，供家长自主复核」。我们实测过这个设计：
把低置信事件放进不响铃档，**29 次致命级发作有 26 次落在了静默档**，响铃档只覆盖 10%。
所以本方案 `engine/tiers.py` 里 `SILENT_TIERS` 恒为空、`rings()` 恒 True ——
**分级只决定「怎么响」，不决定「是否响」**，并由 `tests/test_gyro_tiers.py` 锁死。
赛题「低刺激」的诉求应该靠**响的方式**（柔光、渐强音）实现，不能靠不响实现。

**3. 瓶颈在特征判别力，不在融合策略或模型。**
五通道并集 = 体动 ∪ 心率 = 23/23，新增通道独家救回 **0** 次发作。
被救回的发作在「角速度占比 / 体动峰 / 心率峰」三维上**全部落在误报分布内部**。
别再试多路投票、阈值微调或换模型 —— 先换能分开「翻身」和「阵挛」的信息。

## 三、已验证的死路（别重走）

- 响铃后按持续性自动撤回 → 任何能撤回误报的门槛都会误撤真发作
- 事件级封顶 / 预算排序 → 单调标量门槛会静默吃掉真发作（曾压掉 2154 次响铃，把 22/22 伪装成 16/22）
- LLM 进实时判决路径 → 只否决 0.9% 的误报，只能做事后过滤
- 体位门（倾角）在院内数据上 → 发作本身污染重力估计，需家庭数据才测得准

## 七、评估口径（复现时必须对齐，否则数字不可比）

1. **按发作类型分层**：致命级（`sz_foc_f2b` / `sz_gen_*`）与非致命（tonic/clonic/myoclonic）必须分开报，混在一起会把 20/23 平均成 65%
2. **事件级和响铃级两把尺子一起报**：9 个误报事件可以等于 2846 次响铃
3. **用留一法，不报全集最优**：17 个正样本配 6 个旋钮，全集「零漏报」被 LOO 推翻过两次
4. **背景时长要对齐**：2h → 12h 背景，同工作点误报从 1.15 涨到 1.55/h
5. **缺通道的记录不能静默剔除**：曾有 3 次致命级发作因缺电极从分母消失，31 被当成 28
