## 这个 Demo 在做什么

合成信号驱动**真实的判据引擎**逐窗推理 —— 调参数后引擎当场算，不是播放预渲染结果。
合成信号不含任何患者数据，固定种子可复现。

- 8 秒窗 / 4 秒步进，一夜约 5400 个推理窗口
- 事件级按 300 秒间隔归并，**同时报事件级和响铃级两把尺子**
- 事件表给出每次响铃的主驱动与证据链

## 真实数据上的成绩（可引用的数字）

> **致命级发作（继发全身化 + 阵挛期，与 SUDEP 相关）23 次检出 23 次，
> 代价是误报 6.70 次/10 夜。** 两个数字必须一起看。

`6.70 次/10夜` = `0.105 次/小时`（致命级队列 242h / 38 夜 = 6.37 小时/夜）。
自定目标 0.05 次/小时，**实际差 2.1 倍 —— 没达标**。

数据来源：SeizeIT2（佩戴式，胸贴 + 耳后贴片）、CHB-MIT。
**本 Demo 用的是合成信号，只用来看引擎怎么决策，不代表真实性能。**

## 和赛题需求书的差距

| 赛题要求 | 实际 |
|---|---|
| 「完全无穿戴、无束缚」 | ❌ 全部结论基于佩戴式传感器。判据本身与前端形态无关 |
| 五路融合（心率/呼吸/血氧/体温/体动） | ⚠️ 只实测心率和体动；呼吸由 ECG 反推（覆盖 72%）；血氧体温数据集无通道 |
| 「隐匿发作」识别 | ❌ 抓不到。背景有 10.8% 的时间心率也超过自身 1.5 倍，是信噪比问题 |
| 分级预警 | ✅ 已做，但**无静默档**（实测 29 次致命级发作有 26 次落在静默档） |
| 夜间事件时间轴 | ✅ 已做 |
| 多监护人协同 / 低刺激硬件 / 发热模式 | ❌ 未做 |

样本量：致命级发作仅 23 次，认证口径 recall ≥99% 需 161 次。
